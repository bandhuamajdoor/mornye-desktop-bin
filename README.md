# Mornye Desktop for Arch Linux

Unofficial Arch Linux packaging for [Mornye Desktop](https://github.com/mornyeapp/Mornye-Desktop).

## Install

Install the required tools:

    sudo pacman -S --needed base-devel git

Clone this repository and build the package:

    git clone https://github.com/bandhuamajdoor/mornye-desktop-bin.git
    cd mornye-desktop-bin
    makepkg -si
